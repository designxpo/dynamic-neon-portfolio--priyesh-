# Backlink Playbook — Priyesh Mishra

**Goal:** earn quality backlinks + citations to `priyeshmishra.com` for **global** clients across **Development (app / software / website)**, **SEO / AEO / GEO**, and **Design**.

Backlinks are *off-page* — no code can create them. They come from other sites choosing to link to you, earned through (1) a link-worthy asset, (2) distribution/outreach, and (3) legitimate listings. This doc is the operating manual. The site now ships the asset (the **Project Cost Estimator** at `/tools/project-cost-estimator`) — the rest is execution.

> ⚠️ **Never buy links or use PBNs / fiverr "1000 backlinks" gigs.** They cause Google penalties and waste money. Everything below is white-hat.

## 1. The linkable asset — the Project Cost Estimator

**URL:** `https://www.priyeshmishra.com/tools/project-cost-estimator`

Free cost calculators are the #1 organic link magnet in this niche — bloggers and journalists cite them ("according to [tool], a web app costs…"), and the tool is **embeddable** (each embed = a backlink).

**How to turn it into links:**
1. **Launch it on Product Hunt** (see §3) — instant DR-90 backlink + traffic.
2. **Pitch it to "how much does X cost" articles.** Search Google for `how much does it cost to build a website 2026`, `app development cost`, `software development cost` — email the authors offering your estimator as an interactive resource (template in §5).
3. **Offer the embed** to agency/freelancer blogs and comparison sites. The "Embed `<iframe>`" button on the tool copies the snippet for them.
4. **Answer pricing questions** on Reddit/Quora/IndieHackers and link the specific estimate (the URL carries the exact configuration).

## 3. Product Hunt launch (highest single-day ROI)

1. Create a maker account; build a small following first (follow/engage 1–2 weeks ahead).
2. Prepare: tagline, 3–5 gallery images/GIF of the estimator, first comment (the story), and 2–3 topics (`Design Tools`, `Developer Tools`, `SEO`).
3. Launch **12:01 AM PT**, ideally Tue–Thu. Rally your network in the first 2 hours.
4. Result: a strong dofollow-ish backlink, referral traffic, and often secondary pickups (newsletters, "best tools" roundups) that link you.

Also submit to: **Fazier, Uneed, SaaSHub, BetaList** the same week (they syndicate launches).

### C) Unlinked-mention → link reclaim
Set a Google Alert / search for "Priyesh Mishra" mentions that don't link you.
> Hi [Name], thanks for mentioning my work in [article]! Would you mind linking my name to https://www.priyeshmishra.com so readers can find the portfolio? Much appreciated. — Priyesh

### D) HARO / Featured / Qwoted (journalist requests)
Sign up (free) and answer queries about web design, development cost, SEO/AI search. A concise, quotable, first-hand answer earns links from high-authority news/blog sites. Answer within the hour, lead with the specific insight, keep it 80–120 words.

## 6. Content that attracts links (self-publish + syndicate)

Publish on your own `/blog` first (canonical), then syndicate to **DEV.to, Hashnode, Medium** with a `rel=canonical` back to your post. Topics that earn links in your niches:

- **"How much does it cost to build a [website / web app / mobile app] in 2026?"** — pair with the estimator. Ranks for high-intent queries and gets cited.
- **"AEO & GEO explained: how to get your site cited by ChatGPT, Perplexity & Google AI"** — hot, under-covered topic → citations.
- **A real case study with numbers** (before/after metrics). First-hand data is the most link-worthy content there is.
- **A comparison / decision guide** ("Next.js vs. WordPress for a startup site") — comparison content attracts links.

Each post: add internal links to `/tools/project-cost-estimator`, `/projects`, `/#services`.

## 8. Measure

- **GSC → Links report:** total external links + top linking sites (monthly).
- A free Ahrefs Webmaster Tools / Ubersuggest account for referring-domains count.
- Track referral traffic in GA4 (`Acquisition → Traffic acquisition → Referral`).
- **North-star metric:** referring domains (unique sites linking you), not raw link count. Aim for +5–10 quality referring domains/month.
